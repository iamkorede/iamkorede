## 🚀 **Quick Start Guide**

### **backend-wizards-profile-endpoint**

```bash
# 🔗 Clone the repository
git clone https://github.com/iamkorede/backend-wizards-profile-endpoint.git
cd backend-wizards-profile-endpoint

# 📦 Install dependencies
npm install

# ▶️ Start the development server
npm start

# 🧪 Test the endpoint
curl http://localhost:3000/api/profile
```
